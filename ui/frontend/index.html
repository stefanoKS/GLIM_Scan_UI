Official GLIM tools
Open native GLIM windows on this server's desktop (or a Jetson with a connected display). For a remote browser, use the workstation desktop to interact. Edits start from separate working copies.
Save changes in the native application to the displayed saved_map folder, then close the window. Closing does not save edits.
Native tool workflows
Manual loops: In offline_viewer, choose Loop begin and Loop end on submap spheres, align the clouds, inspect registration, then create a factor. Plane constraints and graph recovery are available in the same viewer.
Merge: Open the first copied map and allow optimization. Use File → Open Additional Map for each additional copied path. Merge sessions → coarse alignment → fine registration → inspect → Create factor. Then find overlapping submaps and optimize.
Segmentation: In map_editor, right-click an object for MinCut, or a plane for RegionGrowing. Inspect selected points before removal. Gizmo and radius tools support manual cleanup and outlier removal. Poses remain fixed while editing points.
